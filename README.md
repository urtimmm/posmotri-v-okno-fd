# Посмотри в окно

Учебный проект: веб-приложение для просмотра видео по городам и времени суток.

## Описание

Приложение загружает видео с сервера и отображает:

- основное видео;
- список карточек с видео;
- возможность подгрузки дополнительных карточек;
- поиск по городу и времени суток.

При клике на карточку меняется основное видео.

Во время загрузки отображаются прелоадеры, при ошибке — сообщение об ошибке.

## Технологии

- HTML
- CSS (Flexbox, BEM)
- JavaScript (DOM, работа с API)
- `<template>` для динамической разметки
